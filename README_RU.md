# WB Profit Bot v29 — прибыль, остатки и мониторинг приёмки

Бот получает данные через WB API, принимает детализацию реализации в формате `.xlsx` и считает:

- проданные единицы;
- доход покупателей;
- расчётную выплату после расходов WB;
- себестоимость;
- УСН 1% «Доходы»;
- чистую прибыль и маржинальность;
- результат по каждому артикулу.

Также бот автоматически проверяет доступные даты приёмки FBW и присылает уведомление в Telegram. По умолчанию включены короба и склады Центрального федерального округа, включая Рязань.

Рекламные расходы загружаются через WB API, если токену выданы необходимые права.

## Что находится в папке

- `bot.py` — Telegram-бот;
- `wb_acceptance.py` — мониторинг тарифов и доступности приёмки WB;
- `wb_profit.py` — расчёт прибыли;
- `data/costs.xlsx` — твой файл себестоимости;
- `requirements.txt` — необходимые библиотеки;
- `railway.json` — команда запуска на Railway;
- `.env.example` — названия секретных переменных и настройки мониторинга.

## Важно о безопасности

1. Создавай репозиторий GitHub только как **Private**. В папке лежит твоя себестоимость.
2. Никогда не загружай токен Telegram-бота в GitHub и не вписывай его в файлы проекта.
3. Токен добавляется только в разделе Variables на Railway.
4. Если токен когда-либо попал в общий доступ, отзови его через BotFather и создай новый.

## Запуск через GitHub и Railway

### 1. Подготовь GitHub

1. Создай аккаунт GitHub.
2. Нажми `New repository`.
3. Название: `wb-profit-bot`.
4. Выбери **Private**.
5. Создай репозиторий без дополнительных файлов.
6. Распакуй архив проекта на компьютере.
7. В репозитории нажми `Add file` → `Upload files`.
8. Загрузи все файлы и папку `data` так, чтобы `bot.py` находился в корне репозитория.
9. Нажми `Commit changes`.

### 2. Создай сервис Railway

1. Войди в Railway через GitHub.
2. Нажми `New Project` → `Deploy from GitHub repo`.
3. Выбери приватный репозиторий `wb-profit-bot`.
4. Railway определит Python-проект и установит зависимости.
5. Открой созданный сервис → `Variables`.
6. Добавь переменную:
   - имя: `BOT_TOKEN`
   - значение: секретный токен от BotFather без кавычек.
7. Добавь `WB_API_TOKEN` — персональный токен из кабинета продавца WB.
8. Примени изменения и запусти повторное развёртывание, если Railway его не начал автоматически.
9. В логах должна появиться строка `WB Profit Bot v29 запущен`.

Для Telegram-бота на long polling публичный домен не нужен. База данных на первом этапе также не нужна.

### 3. Проверь бота

1. Открой своего бота в Telegram.
2. Нажми `Start` или отправь `/start`.
3. Отправь тот же файл детализации WB как документ `.xlsx`.
4. Бот должен показать прибыль `1 471,76 ₽` для тестового отчёта за 04–10 мая 2026 года.

### 4. Закрой доступ

1. Отправь боту `/id`.
2. Скопируй полученное число.
3. В Railway → `Variables` добавь:
   - имя: `ALLOWED_USER_ID`
   - значение: твой Telegram ID.
4. Примени изменения.

После этого бот будет отвечать только твоему Telegram-аккаунту.

После добавления `ALLOWED_USER_ID` автоматически запустится и мониторинг приёмки: сообщение придёт при появлении новой подходящей даты или снижении коэффициента с ×1 до бесплатного.

## Мониторинг приёмки WB

Команды:

- `/acceptance` — проверить доступную приёмку прямо сейчас;
- `/acceptancesettings` — показать активные фильтры;
- `/acceptancetest` — проверить доставку Telegram-уведомлений;
- `/schedule` — увидеть, запущена ли автоматическая проверка.

Настройки добавляются в Railway → Variables:

```env
AUTO_ACCEPTANCE_MONITOR=true
ACCEPTANCE_ALL_REGIONS=true
ACCEPTANCE_WAREHOUSE_NAMES=Рязань,Коледино,Электросталь,Подольск,Тула,Алексин,Котовск,Софьино,Белая дача,Чехов,Владимир,Ярославль
ACCEPTANCE_REQUIRED_WAREHOUSE_NAMES=Питание
ACCEPTANCE_WAREHOUSE_IDS=
ACCEPTANCE_BARCODES=
ACCEPTANCE_BOX_TYPE_IDS=2
ACCEPTANCE_MAX_COEFFICIENT=1
ACCEPTANCE_DAYS_AHEAD=14
ACCEPTANCE_CHECK_INTERVAL_SECONDS=120
```

- `ACCEPTANCE_ALL_REGIONS=true` — следить за пищевыми складами во всех регионах России;
- `ACCEPTANCE_ALL_REGIONS=false` — ограничить поиск городами из `ACCEPTANCE_WAREHOUSE_NAMES`;
- `ACCEPTANCE_WAREHOUSE_NAMES=Рязань` — при выключенном режиме всех регионов следить только за складами Рязани;
- `ACCEPTANCE_REQUIRED_WAREHOUSE_NAMES=Питание` — исключить обычную Рязань и другие склады, которые не относятся к категории «Питание»;
- `ACCEPTANCE_BARCODES=1234567890123,9876543210987` — дополнительно проверить через WB, что склад принимает именно эти баркоды. Если указано несколько баркодов, бот оставит склады, принимающие их все;
- `ACCEPTANCE_BOX_TYPE_IDS=2` — поставка коробами;
- `ACCEPTANCE_MAX_COEFFICIENT=0` — только бесплатная приёмка;
- `ACCEPTANCE_MAX_COEFFICIENT=1` — вся приёмка, которую WB разрешает для поставки;
- проверка выполняется раз в 120 секунд и не присылает одну дату повторно;
- совместимость складов с баркодами обновляется не чаще одного раза в 6 часов, чтобы не превышать лимиты WB API;
- после перезапуска Railway текущие доступные даты могут прийти повторно один раз.

По умолчанию бот ищет склады со словом `Питание` во всех регионах России. Чтобы включить точную проверку товара, скопируй баркоды из карточек WB и добавь их через Railway → Variables в переменную `ACCEPTANCE_BARCODES`, разделяя запятыми. Токен `WB_API_TOKEN` должен иметь категорию `Поставки`.

Команда `/acceptance` показывает и открытые даты, и найденные пищевые склады, на которых сейчас нет мест. Автоматические уведомления приходят только при появлении доступной даты.

Бот только уведомляет. Забронировать дату нужно вручную в кабинете WB.

## Как обновить уже работающий бот

1. Распакуй готовый архив.
2. Открой приватный репозиторий `wb-profit-bot` на GitHub.
3. Нажми `Add file` → `Upload files`.
4. Перетащи всё содержимое распакованной папки, сохранив папку `data`.
5. Подтверди замену файлов и нажми `Commit changes`.
6. Railway автоматически начнёт новый Deploy.
7. После запуска отправь боту `/acceptancetest`, затем `/acceptance`.

## Как обновлять себестоимость

1. Обнови свой Excel-файл, сохранив колонки:
   - `Артикул поставщика`;
   - `Название`;
   - `себестоимость`.
2. Переименуй файл в `costs.xlsx`.
3. В приватном репозитории открой папку `data`.
4. Замени старый `costs.xlsx` новым и нажми `Commit changes`.
5. Railway автоматически развернёт новую версию.

## Локальная проверка на компьютере — необязательно

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
python test_local.py "C:\путь\к\отчёту.xlsx"
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python test_local.py "/путь/к/отчёту.xlsx"
```

Для запуска самого бота локально создай файл `.env`:

```env
BOT_TOKEN=твой_секретный_токен
WB_API_TOKEN=твой_персональный_токен_WB
ALLOWED_USER_ID=
```

Затем выполни:

```bash
python bot.py
```
